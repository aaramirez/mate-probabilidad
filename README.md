# Probabilidad

La teoría de la probabilidad de un curso universitario completo: axiomas y σ-álgebras, probabilidad condicional y Bayes, variables y vectores aleatorios, momentos y funciones generatrices, los modelos discretos y continuos, la normal multivariante, sus distribuciones derivadas y las formas cuadráticas.

**Ver en línea:** https://aaramirez.github.io/mate-probabilidad/

Este repositorio solo tiene el sitio generado. El curso está en preparación: la tabla de contenido ya está publicada para revisión.
